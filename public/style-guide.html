Rules

No inline stylesUse role classes and tokens. If a value is missing, add a token to css/fonts.css.
No hand-set typeDon't write font-family / font-size in page CSS. Pick a role.
Display is regular weightInstrument Serif has no bold; size and tracking carry hierarchy.
px-based sizesRole tokens use px so they match on Bootstrap 3 pages (html { font-size: 10px }).
