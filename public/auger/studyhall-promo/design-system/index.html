STUDYHALL
DESIGN SYSTEM

Tokens, animations and components extracted from the StudyHall game: a phosphor-green terminal aesthetic on near-black, hard pixel corners, one monospace face for UI and one pixel face for headings. Click any animation tile to replay it.

Usage

Green is the only accent. It is text, border and hover fill. Never use it as a large background except the bright prompt card. Red/amber are reserved for time pressure and score tone. Purple belongs to pop-up windows and the word cloud.
